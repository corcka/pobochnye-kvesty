# Побочные квесты · Том 1

> Я переродился в спальном районе у Пятницкого шоссе, и теперь каждые выходные мы с напарником выполняем побочные квесты, которые нам выдаёт колода карт

Карточная игра для прогулок вдвоём. Колода из 100 карт: Найди, Сними, Сделай, Придумай, Профдеформация, Блокнот, Тайная и Модификаторы.

**Посмотреть колоду:** https://corcka.github.io/pobochnye-kvesty/

Карты листаются стрелками или свайпом, наклоняются за мышью и переворачиваются по клику. Кнопка «Тянуть карту» выдаёт случайное задание.
